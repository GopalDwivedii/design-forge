# Two-minute demo script

1. Open **Practice** and choose **Adaptive Parking Lot**.
2. Point out the bounded requirements, constraints, and “design signals” in the brief.
3. Select **Use brief scaffold**, add a few object responsibilities and an invalid-ticket flow, then submit.
4. While the review is pending, show that the attempt has been saved and the UI communicates an explicit evaluation state.
5. When the review resolves, explain that the feedback is rubric-first: every dimension offers visible evidence and a concrete next move, not a claim that one diagram is correct.
6. Open **My attempts**. Select the saved attempt to show the retained submission, criterion feedback, and learning trail.
7. Mention the implementation seam: swapping the deterministic evaluator for an LLM or human-review adapter does not change `Attempt` lifecycle or history.
